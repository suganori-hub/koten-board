目標：

すべて縦書きで、右から本文→現代語訳→語句→文法の順に並びます。表示する項目だけが画面いっぱいに大きく表示されます。本文の文字を選択して「強調」を押すと色が付きます。同じ番号の本文・現代語訳はタップで相互にハイライト、語句カードをタップすると本文中の該当箇所が光ります。

AI自動入力の設定

「教材編集」の「✨ AIで語句・文法を自動入力」で使います。あなた自身の Anthropic APIキー（console.anthropic.com で発行）を、この端末にだけ保存します。利用料はキーの持ち主（APIの従量課金）にかかります。キーが無ければ、このボタンは使われず他の機能に影響しません。

自動入力時、本文（と既存の語句名）がAnthropicのサーバーに送信されます。生徒の個人情報は入力しないでください。AIの出力は下書きで、誤りが含まれることがあります（特に活用形・助動詞の識別）。各項目の「AI下書き」表示は、あなたが「確認済み」を押すまで残り、板書プレビューにも「AI下書き」と表示されます（投影画面には出ません）。APIキーは同期されません。端末ごとに登録してください。

端末間の同期（PC⇔iPad）

教材・強調・手書きを、あなたの非公開GitHubリポジトリに保存して端末間で共有します（追加サーバー・有料サービスは不要）。一度設定すると、編集は数秒で自動送信され、他端末は起動時・画面を開いたとき・1分ごとに自動で取り込みます。

  1. GitHubでPrivate（非公開）リポジトリを作成します（例：koten-data）。「Add a README file」にチェックを入れてください。
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 「Generate new token」。
    Repository access は「Only select repositories」で上のリポジトリだけを選び、Permissions → Contents: Read and write にして生成します。
  3. 下の欄にリポジトリ名とトークンを入れて「接続して同期」を押します。
  4. 2台目以降は、この端末で「接続コードを作る」→ 別の端末の「接続コードを貼り付け」欄へ貼り付けると設定が一瞬で終わります。

未設定

接続コードとトークンはパスワードと同じです。他人に見せないでください。リポジトリは必ず非公開にしてください（教材の著作権・教師用メモが含まれます）。同じ教材を2台で同時に編集した場合は、新しく保存した方が採用されます。

使い方

  1. 左の「＋ 新規」から授業教材を作ります。入力した内容は自動で保存され、板書・投影にもすぐ反映されます。
  2. 本文は1行＝縦書きの1列です。現代語訳は本文と同じ行数で入力すると、番号で対応します。
  3. 語句・品詞・文法事項は「＋ 助動詞」などのボタンで追加し、品詞・活用の種類・活用形・意味・説明を入力します。
  4. 「板書プレビュー」「投影モード」は、本文・現代語訳・語句・文法のすべてが縦書きで、右から左へ並びます。表示する項目だけが画面いっぱいに大きくなります（「自動で大きく」）。「。」ごとに自動で改行して短く表示できます（「「。」で改行」。入力した本文自体は変わりません）。見出しも隠せます。
  5. 「✨ AIで語句・文法を自動入力」（要APIキー）で、本文から語句・品詞・活用・意味・文法説明の下書きを作れます。必ず内容を確認してください。
  6. 投影モードは←→キーまたは「次へ」で、本文→現代語訳→語句→文法の順に提示できます。
  7. 手書きはApple Pencilで画面に触れると自動で手書きONになります（指では描きません。指でのタップは通常どおり反応します）。

板書の大きさと手書きについて

板書は常に「16:9の固定サイズ」で組まれ、画面に合わせて拡大縮小されます。そのため、画面の大きさ・向き・端末が変わっても配置は崩れず、手書きの位置もずれません。手書きは表示内容の組み合わせ（本文のみ／本文＋解説／解説のみ）ごとに保存されます。表示内容が変わると文字の位置が変わるためです。

文法候補抽出について

助動詞・係助詞などの文字列を検索して候補を示す補助機能です。形態素解析や文脈判断は行いません。活用形・接続・意味・係り結びは必ず確認してください。

個人情報・成績情報・生徒名などは入力しないでください。共有端末では利用後にブラウザのデータ管理にも注意してください。
