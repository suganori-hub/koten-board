目標：

本文の文字を選択して「強調」を押すと、選んだ語句に色が付きます。右の本文・左の現代語訳は、同じ番号の行どうしが対応します（タップで相互にハイライト）。語句カードをタップすると本文中の該当箇所が光ります。

使い方

  1. 左の「＋ 新規」から授業教材を作ります。入力した内容は自動で保存され、板書・投影にもすぐ反映されます。
  2. 本文は1行＝縦書きの1列です。現代語訳は本文と同じ行数で入力すると、番号で対応します。
  3. 語句・品詞・文法事項は「＋ 助動詞」などのボタンで追加し、品詞・活用の種類・活用形・意味・説明を入力します。
  4. 「板書プレビュー」で右に縦書き本文、左に現代語訳・語句・文法を確認します。
  5. 「投影モード」で全画面表示。←→キーまたは「次へ」で、本文→現代語訳→語句→文法の順に提示できます。
  6. 手書きは「✎ 手書き」をONにし、Apple Pencilで書きます（指では描かない設定が標準）。元に戻す・消しゴム・全消去が使えます。

投影モードのキー操作

→ / Space：次へ　← ：戻る　A：全表示　1〜4：本文・現代語訳・語句・文法の表示切替　＋ / −：文字サイズ　D：手書きON/OFF　E：消しゴム　Ctrl+Z：元に戻す　Esc：終了

Windows PC・iPadでの利用

教材データは端末ごとのブラウザ内（localStorage）に保存されます。端末間の移行には「全教材を書き出す／教材を読み込む」を使ってください。ブラウザのサイトデータを消すと教材も消えるため、定期的に書き出してバックアップしてください。

手書きの位置について

手書きは「板書プレビュー」と「投影モード」で別々に保存されます（画面ごとに文字の配置が異なるため）。v2で書いた手書きは両方に表示されます。

文法候補抽出について

助動詞・係助詞などの文字列を検索して候補を示す補助機能です。形態素解析や文脈判断は行いません。活用形・接続・意味・係り結びは必ず確認してください。

個人情報・成績情報・生徒名などは入力しないでください。共有端末では利用後にブラウザのデータ管理にも注意してください。
