授業メモ（教師用）

教師用メモは通常の板書プレビューでは非表示です。投影モードにも表示しません。

使い方

  1. 左の「＋ 新規」から授業教材を作ります。
  2. 本文・現代語訳・重要語句や文法を入力します。
  3. 「板書プレビュー」で表示を確認します。
  4. 「投影モード」で全画面表示し、「次を表示」で段階的に提示します。
  5. 板書プレビューの「手書き：ON」を押すと、Apple Pencilやマウスで本文上に書き込めます。描画は教材ごとに保存されます。
  6. 教材はこのブラウザ内に自動保存されます。別端末へ移す場合はJSONを書き出して読み込みます。

Windows PC・iPadでの利用

GitHub Pagesに公開すると、同じURLを両方の端末で開けます。現段階では教材データは端末ごとに保存され、自動同期はしません。端末間の移行には書き出し・読み込みを使ってください。

文法候補抽出について

助動詞・係助詞などの文字列を検索して候補を示す補助機能です。古文の形態素解析や文脈判断を行うAI解析ではありません。活用形・接続・意味・係り結びは必ず確認してください。

今後の拡張候補

  • クラウド同期・アカウント管理
  • AIによる品詞分解・現代語訳の下書き（API接続が必要）
  • 教材テンプレート・年間授業計画
  • 生徒配布プリントのレイアウト出力
個人情報・成績情報・生徒名などは入力しないでください。共有端末では利用後にブラウザのデータ管理にも注意してください。
