目標：

すべて縦書きで、右から本文→現代語訳→語句→文法の順に並びます。表示する項目だけが画面いっぱいに大きく表示されます。本文の文字を選択して「強調」を押すと色が付きます。同じ番号の本文・現代語訳はタップで相互にハイライト、語句カードをタップすると本文中の該当箇所が光ります。

📄配布プリント（穴埋め・確認小テスト）
入力済みの本文・現代語訳・語句から自動で作ります

穴埋め・確認問題にする語句は、「教材編集」で各語句の「穴埋め・確認問題にする」にチェックを入れたものです（1つも選んでいなければ、本文に出てくるすべての語句）。印刷画面で「PDFに保存」を選ぶとPDFになります。

AI自動入力の設定

「教材編集」の「✨ AIで語句・文法を自動入力」で使います。あなた自身の Anthropic APIキー（console.anthropic.com で発行）を、この端末にだけ保存します。利用料はキーの持ち主（APIの従量課金）にかかります。キーが無ければ、このボタンは使われず他の機能に影響しません。

自動入力時、本文（と既存の語句名）がAnthropicのサーバーに送信されます。生徒の個人情報は入力しないでください。AIの出力は下書きで、誤りが含まれることがあります（特に活用形・助動詞の識別）。各項目の「AI下書き」表示は、あなたが「確認済み」を押すまで残り、板書プレビューにも「AI下書き」と表示されます（投影画面には出ません）。APIキーは同期されません。端末ごとに登録してください。

端末間の同期（PC⇔iPad）

教材を編集する端末は1台（編集端末）だけにします。他の端末（閲覧端末）は、編集端末で作った教材・強調・手書きを表示するだけで、編集・追加・削除はできません。データは、あなたの非公開GitHubリポジトリを経由します（追加サーバー・有料サービスは不要）。編集端末の変更は数秒で送信され、閲覧端末は起動時・画面を開いたとき・30秒ごとに自動で最新になります。

  1. GitHubでPrivate（非公開）リポジトリを作成します（例：koten-data）。「Add a README file」にチェックを入れてください。
  2. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → 「Generate new token」。
    Repository access は「Only select repositories」で上のリポジトリだけを選び、Permissions → Contents: Read and write にして生成します。
  3. 編集端末で、役割を「編集端末」にして、リポジトリ名とトークンを入れ「接続して同期」を押します。
  4. 編集端末で「閲覧端末用の接続コードを作る」→ 閲覧にしたい端末の「接続コードを貼り付け」欄に貼って「コードを読み込んで接続」。自動で「閲覧専用」になります。

閲覧端末でも、授業中のApple Pencilによる手書き・文字サイズ変更・投影は使えます。閲覧端末で書いた手書きはその端末だけに残り、編集端末へは送られません（編集端末の手書きは閲覧端末にも表示されます）。

未設定

接続コードとトークンはパスワードと同じです。他人に見せないでください。リポジトリは必ず非公開にしてください（教材の著作権・教師用メモが含まれます）。編集端末を2台にすると、新しく保存した方が採用されます（1台に絞ることをおすすめします）。

使い方

  1. 左の「＋ 新規」から授業教材を作ります。入力した内容は自動で保存され、板書・投影にもすぐ反映されます。
  2. 本文は1行＝縦書きの1列です。現代語訳は本文と同じ行数で入力すると、番号で対応します。
  3. 語句・品詞・文法事項は「＋ 助動詞」などのボタンで追加し、品詞・活用の種類・活用形・意味・説明を入力します。
  4. 「板書プレビュー」「投影モード」は、本文の一文ごとに、右から「本文 → 現代語訳 → 語句 → 文法」が縦書きで並びます（1文目が右端）。入力した本文は「。」ごとに一文に区切られます。
  5. 「次へ」を押すたびに、次の一文の解説（現代語訳・語句・文法）が出ます。本文は先に見えているので、読んでから解説を出せます。画面に入りきらない分は自動で次の画面に切り替わります。「一度に表示する文」で1画面の文数を選べます。
  6. 語句・文法が違う文に表示されるときは、教材編集の各項目の「表示する文」で何文目かを指定してください（通常は「自動」で、本文中に語句が出てくる文に表示されます）。
  7. 「✨ AIで語句・文法を自動入力」（要APIキー）で、本文から語句・品詞・活用・意味・文法説明の下書きを作れます。必ず内容を確認してください。
  8. 投影モードは←→キーまたは「次へ」で、本文→現代語訳→語句→文法の順に提示できます。
  9. 手書きはApple Pencilで画面に触れると自動で手書きONになります（指では描きません。指でのタップは通常どおり反応します）。

投影モードのキー操作

→ / Space / Enter：次の文の解説　← ：前に戻る　A：この画面を全部表示　Home：最初から　1〜4：本文・現代語訳・語句・文法の列の表示切替　＋ / −：文字サイズ　F：自動拡大のON/OFF　K：「。」で区切る/区切らない　T：ツールバーの表示/非表示　D：手書き　E：消しゴム　Ctrl+Z：元に戻す　Esc：終了

板書の大きさと手書きについて

板書は常に「16:9の固定サイズ」で組まれ、画面に合わせて拡大縮小されます。そのため、画面の大きさ・向き・端末が変わっても配置は崩れず、手書きの位置もずれません。手書きは表示内容の組み合わせ（本文のみ／本文＋解説／解説のみ）ごとに保存されます。表示内容が変わると文字の位置が変わるためです。

文法候補抽出について

助動詞・係助詞などの文字列を検索して候補を示す補助機能です。形態素解析や文脈判断は行いません。活用形・接続・意味・係り結びは必ず確認してください。

個人情報・成績情報・生徒名などは入力しないでください。共有端末では利用後にブラウザのデータ管理にも注意してください。
