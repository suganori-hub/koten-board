# KOTEN BOARD v4｜高校古典・授業支援システム

## v5.1の追加（iPad閲覧・PC編集・指名）
- **「↺ 自動サイズに戻す」ボタン**：手動で文字サイズを変えた後、ワンタップで「自動で大きく」に戻せる（板書プレビュー・投影の両方。自動のときは無効表示）。
- **iPad閲覧向け**：キーボード不要。画面下に大きな「◀前へ／次へ▶」ボタン（板書プレビュー・投影）、投影中は左右スワイプでも進む（左→次、右→前）。タッチ端末ではボタン・タブ・チェックを44px以上に拡大。ツール欄を隠しても下のボタンと「🎯指名」は残る。
- **PC編集向け**：幅の広い画面では左に「授業情報・本文・訳・メモ」、右に「語句・文法」を並べ、スクロールを減らした。Ctrl+S で保存、Ctrl+Enter で板書プレビューへ。
- **🎯 出席番号で指名**：番号の範囲（例 1〜40）から1〜5人をランダム抽選。欠席番号を除外（例「3, 15, 20-22」）、当たった番号を次回から除く設定、履歴リセット付き。投影中も画面上部/下部の「🎯指名」（Rキー）で使える。設定は端末内に保存（教材・同期データには含まれない）。
- 全表示のまま最初に「次へ」を押すと、一文目から解説が始まる。

## v5の変更点（一文ごとの解説表示）
- **「見出し」欄を廃止**：その分、本文・現代語訳を大きく表示。
- **一文ごとに横並び**：「日もいと長きに、～」のすぐ左に現代語訳「（春の）日もたいそう長いうえに、～」、その左に語句、さらに左に文法を縦書きで表示（右から 本文→現代語訳→語句→文法）。
- **「次へ」で一文ずつ解説**：最初は本文だけ。「次へ ▶」（投影中は→・Space）を押すごとに次の一文の訳・語句・文法が出る。「◀前へ」で戻る、「この画面を全部表示」(A/End)、「最初に戻す」(Home)。解説の場所は先に確保されるので、押しても本文は動かない。
- **一度に表示する文**：自動／1〜4文／全部。解説が次の画面の文に進むと自動でページが切り替わる。
- **語句・文法の割り当て**：本文にその語が出てくる文に自動で表示。ずれる時は編集タブの各項目「表示する文」で指定。どの文にも当てはまらない項目は最後の「ほか」に表示。
- 本文と現代語訳の文の数が違うと、編集画面に警告が出る（「。」「！」「？」区切り）。
- 手書きは画面（文の組み合わせ）ごとに保存。v4以前のレイアウトで書いた手書きは新レイアウトでは表示されません（データは残ります）。

## v4からの機能（継続）
- **AIで語句・文法を自動入力**（利用者自身のAnthropic APIキーが必要・任意）。「AI下書き」表示は確認済みにするまで残る。
- **手書きが崩れない**：1600×900の固定ステージで拡縮。Pencilが触れると自動で手書きON。
- **端末間同期（編集は1台・他は閲覧専用）**：非公開GitHubリポジトリ経由。

## 設置
`index.html` `app.js` `style.css` `sw.js` を既存リポジトリに上書きし、`README.md` も更新して push。`manifest.webmanifest` は既存のまま。

## 同期の設定（1回だけ）
1. GitHubで **Private** リポジトリを作成（例：`koten-data`、README付き）。
2. Settings → Developer settings → Fine-grained tokens → そのリポジトリだけ選択、**Contents: Read and write**。
3. **編集端末**：「使い方・同期設定」で役割＝編集端末、リポジトリ名とトークンを入れて「接続して同期」。
4. **閲覧端末**：編集端末で「閲覧端末用の接続コードを作る」→ 閲覧端末の「接続コードを貼り付け」へ貼って「コードを読み込んで接続」。自動で閲覧専用になる（この端末の教材は編集端末の内容に置き換わる。置き換え前は `koten-board-v1-before-sync` に退避）。

## データ互換
保存キー `koten-board-v1` と配列形式は従来どおり。v2/v3のデータは自動補完。移行前データは `koten-board-v1-backup-*` に退避。

## 注意
トークン・APIキーはパスワードと同じです。端末のブラウザ内にだけ保存され、同期データには含まれません。
