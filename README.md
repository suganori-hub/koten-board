# KOTEN BOARD v3｜高校古典・授業支援システム

高校古文授業向けの教材準備・板書・投影Webアプリ（Windows PC / iPad、GitHub Pages対応）。

## v3の変更点
- **縦書きレイアウト**：右に縦書きの古文本文（`writing-mode: vertical-rl`）、左に現代語訳・語句/品詞・文法事項。
- 本文と現代語訳は**行番号で対応**（タップで相互ハイライト）。語句カードをタップすると本文中の該当箇所が光る。
- 本文の**大きさ・行間・字間**を調整可能（教材ごとに保存）。選択した語句に**黄/赤で強調**。
- 語句・文法項目：種類、語句、品詞、活用の種類、活用形、意味、文法上の説明。追加・編集・並べ替え・複製・削除。
- 種類別の絞り込みチップ（助動詞・助詞・敬語・係り結び…）で授業中に必要なものだけ表示。
- 手書き：Pencil優先（指では描かない設定が標準）、色、太さ、消しゴム、**元に戻す**、全消去、筆圧。投影モードでも書き込み可。
- 投影モード：本文→現代語訳→語句→文法の段階表示、1〜4キーで個別切替、文字サイズ変更、キーボード操作。
- **編集内容は自動保存**され、板書・投影へ即時反映。
- Service Worker：キャッシュ v3、ネットワーク優先、更新の即時反映。

## データ互換
- 保存キーは従来どおり `localStorage["koten-board-v1"]`（教材の配列）。v2のデータはそのまま読み込み、新項目は自動補完。
- 初回移行時に `koten-board-v1-backup-v2` へ移行前データを退避。読み込み(インポート)前にも `koten-board-v1-before-import` へ退避。
- JSON書き出しは従来と同じ配列形式。v2のJSONもそのまま読み込めます。

## 投影モードのキー
→/Space 次へ ・ ← 戻る ・ A 全表示 ・ 1〜4 本文/現代語訳/語句/文法の切替 ・ +/− 文字サイズ ・ D 手書き ・ E 消しゴム ・ Ctrl+Z 元に戻す ・ Esc 終了

## GitHub Pages
リポジトリ直下の `index.html` `app.js` `style.css` `sw.js`（と既存の `manifest.webmanifest`）を上書きしてcommit/pushしてください。
更新後、初回は一度再読み込みすると新バージョンに切り替わります。

## 注意
生徒の個人情報・成績は入力しないでください。公開権限のない教科書本文をリポジトリに含めないでください。
