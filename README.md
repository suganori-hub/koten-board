# KOTEN BOARD v4｜高校古典・授業支援システム

## v4の変更点
- **すべて縦書き**：本文・現代語訳・語句/品詞・文法事項を縦書きで、右から本文→現代語訳→語句→文法の順に並べて表示。
- **「。」で改行して表示**：入力した本文は変更せず、表示だけ「。」ごとに改行（ON/OFF可）。本文と現代語訳は同じ番号で対応。
- **✨ AIで語句・文法を自動入力**：本文から語句・品詞・活用・意味・文法説明（と空欄なら現代語訳）を下書き（要・利用者自身のAnthropic APIキー。任意機能）。出力は「AI下書き」として表示され、確認済みにするまで印が残る。
- **提示内容を大きく**：表示する項目だけが枠いっぱいに収まるよう文字サイズを自動調整（「自動で大きく」）。見出し・ツール欄は隠せる。
- **手書きが崩れない**：板書は1600×900の固定ステージで組み、画面サイズ・向き・全画面に合わせて拡縮。手書きもステージ座標で保存。Pencilが触れると自動で手書きON、描画中は再レイアウトを保留。
- **端末間同期（編集は1台・他は閲覧専用）**：編集端末で作った教材・強調・手書きが、自分の非公開GitHubリポジトリ経由で他の端末に自動表示される。閲覧端末では編集・追加・削除ができず、何も送信しない。

## 設置
`index.html` `app.js` `style.css` `sw.js` を既存リポジトリに上書きし、`README.md` も更新して push。`manifest.webmanifest` は既存のまま。

## 同期の設定（1回だけ）
1. GitHubで **Private** リポジトリを作成（例：`koten-data`、README付き）。
2. Settings → Developer settings → Fine-grained tokens → そのリポジトリだけ選択、**Contents: Read and write**。
3. **編集端末**：「使い方・同期設定」で役割＝編集端末、リポジトリ名とトークンを入れて「接続して同期」。
4. **閲覧端末**：編集端末で「閲覧端末用の接続コードを作る」→ 閲覧端末の「接続コードを貼り付け」へ貼って「コードを読み込んで接続」。自動で閲覧専用になる（この端末の教材は編集端末の内容に置き換わる。置き換え前は `koten-board-v1-before-sync` に退避）。

## データ互換
保存キー `koten-board-v1` と配列形式は従来どおり。v2/v3のデータは自動補完。移行前データは `koten-board-v1-backup-*` に退避。

## 注意
トークン・APIキーはパスワードと同じです。端末のブラウザ内にだけ保存され、同期データには含まれません。
