# KOTEN BOARD v2｜高校古典・授業支援システム

高校古文授業向けの教材準備・板書・投影Webアプリです。Windows PC / iPad対応。GitHub Pagesで公開できます。

## v2追加：Apple Pencil・手書き描画
- 板書プレビュー上で手書き描画モードをON/OFF
- iPadのApple Pencil、タッチ対応ペン、Windowsのマウス/ペン入力に対応（Pointer Events）
- Pencil等の筆圧情報を線幅に反映（ブラウザ/端末がpressureを提供する場合）
- 色・線幅変更、消しゴム、教材単位の描画全消去
- 描画は教材データと一緒にブラウザ内へ保存
- 投影モードにも同じ描画を表示
- 座標を相対値で保存するため、画面サイズが変わっても板書上の位置を維持

### iPadでの使い方
1. GitHub PagesのURLをSafariで開きます。
2. 板書プレビューへ移動します。
3. 「手書き：OFF」をタップしてONにします。
4. Apple Pencilで本文や余白に書き込みます。
5. 書き終えたら手書きモードをOFFにします。指で画面をスクロールしやすくなります。
6. 投影モードでも描画が表示されます。

注意：Apple Pencilの筆圧取得はiPadOS/Safariの対応状況や入力方式に依存します。筆圧が提供されない場合は標準的な太さになります。手書きモード中はキャンバスがタッチ操作を受け取るため、ページスクロールはOFFにしてから行ってください。

## 既存機能
- 教材の新規作成・編集・複製・削除
- 古文本文、現代語訳、目標、教師用メモ
- 古語・文法・敬語・表現項目
- 文字列ベースの文法候補抽出（簡易補助）
- 板書プレビュー、表示切替、段階表示、全画面投影
- 印刷/PDF、JSONバックアップ・復元
- localStorage保存、Service Workerによる基本オフライン対応

## GitHub Pages公開
1. GitHubでリポジトリを作成。
2. このフォルダ内のファイルをすべてリポジトリのルートにアップロード。
3. Settings → Pages → Deploy from a branch。
4. Branch `main`、フォルダ `/ (root)` を選択してSave。
5. 発行されたGitHub Pages URLをWindows PCとiPadで開く。

## ローカル確認
`python -m http.server 8000` を実行し、`http://localhost:8000` を開きます。PWA/Service WorkerはlocalhostまたはHTTPSで動作します。

## 保存・同期について
教材と描画は端末のブラウザ内 `localStorage` に保存されます。PCとiPadで自動同期はしません。端末間の移行にはJSON書き出し・読み込みを使ってください。ブラウザのサイトデータ削除で消える可能性があるため、定期的にバックアップしてください。

## 文法候補の注意
候補抽出は単純な文字列検索です。形態素解析や文脈判断は行わないため、授業で使う前に教師が確認してください。

## プライバシー・著作権
生徒の個人情報・成績は入力しないでください。公開リポジトリには公開権限のない教科書本文・資料を含めないでください。AI解析機能を将来追加する場合、APIキーをブラウザに埋め込まずサーバー側で管理してください。
